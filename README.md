# 🎮 Unity Multiplayer Physics Prototype

A multiplayer physics sandbox developed with **Unity 6, C#, and Netcode for GameObjects (NGO)**.

### ✨ Features
- 🌐 Host-client multiplayer (up to 4 players).
- 🎮 Synchronized player movement.
- 🏠 Lobby and multiplayer session management.
- 🔄 Late joining and disconnection handling.
- ⚽ Interactive physics objects with grabbing and throwing.
- 🔧 Server-authoritative physics simulation.

### 🛠️ Tech Stack
- **Engine:** Unity 6
- **Language:** C#
- **Networking:** Netcode for GameObjects (NGO)
- **Physics:** Unity Physics / Rigidbody

### 🎮 Controls

| Key | Action |
|---|---|
| WASD | Movement |
| Mouse | Camera rotation |
| B | Spawn a physics ball |
| E | Grab / Drop |
| F | Throw held ball |
| X | Delete held ball |

### 🚀 How to Run
1. Clone the repository.
2. Open the project in Unity 6.
3. Open the `Launch` scene and enter Play Mode.
4. Select **Host** or **Join** to start a multiplayer session.
5. The host starts the game once players have joined.
